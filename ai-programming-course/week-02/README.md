# Week 2 — 编程知识深入

> 目标：系统学习编程基础知识，理解 AI 帮你写的代码背后的原理，从 AI 辅助开发者进阶为独立开发者。

## 为什么需要学这些

你已经能用 AI 构建和部署应用了。但要做出更复杂、更可靠的产品，你需要理解底层知识：

- **理解原理** → 写出更好的提示词，AI 生成的代码更准确
- **读懂代码** → 更快发现 AI 的错误，减少 debug 时间
- **独立解决问题** → AI 解决不了的问题，你自己能搞定
