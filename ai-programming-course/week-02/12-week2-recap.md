## 项目练习建议

学编程最好的方式是做项目。以下是一些适合你当前水平的项目：

### 入门级

- **个人博客** — Markdown 写文章，Next.js 渲染，Supabase 存数据
- **Todo 应用** — 经典 CRUD 练习，加上用户认证
- **记账本** — 收支记录，分类统计，数据可视化

### 进阶级

- **SaaS MVP** — 选一个你想解决的问题，做一个最小可用产品
- **AI 写作助手** — AI 辅助写作、改写、翻译
- **团队协作工具** — 实时协作，多用户，权限管理

### 挑战级

- **开源项目贡献** — 在 GitHub 上找感兴趣的项目，提 PR
- **Chrome 扩展** — 结合 AI 做一个有用的浏览器扩展
- **移动端应用** — 用 React Native 或 Expo 做移动 App

## 继续学习的方向

### 深入技术

- **React 进阶** — 状态管理（Zustand）、动画（Framer Motion）
- **TypeScript 进阶** — 高级类型、类型体操
- **Node.js** — 底层原理、Stream、Worker

### 拓展领域

- **移动开发** — React Native / Expo

### 软技能

- **产品思维** — 用户需求分析、MVP 方法
- **项目管理** — 任务拆解、优先级排序
