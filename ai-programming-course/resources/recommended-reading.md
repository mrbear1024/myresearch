## 推荐阅读顺序

### 第一阶段（跟着课程同步）

1. Next.js 官方教程（nextjs.org/learn）
2. React 官方教程（react.dev/learn）
3. Git 交互学习（learngitbranching.js.org）

### 第二阶段（课程结束后深入）

1. TypeScript 手册（typescriptlang.org/docs/handbook）
2. Supabase 指南（supabase.com/docs/guides）
3. MDN Web 开发指南

### 第三阶段（持续精进）

1. Next.js 文档中的高级主题
2. 关注技术博客和社区更新
3. 阅读开源项目的源码
