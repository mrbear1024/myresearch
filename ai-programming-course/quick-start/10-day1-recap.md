## 常见问题汇总

### 环境问题
- Node.js 版本不对 → 用 nvm 切换版本
- npm install 报错 → 删除 `node_modules` 和 `package-lock.json`，重新安装

### 代码问题
- TypeScript 类型错误 → 让 AI 帮你修复
- 页面不显示 → 检查文件名和路径是否正确
- API 返回错误 → 检查环境变量

### 部署问题
- Vercel 构建失败 → 看构建日志，把错误给 AI 分析
- 线上和本地表现不同 → 检查环境变量是否在 Vercel 中正确配置

## 接下来的学习路径

### Week 1：更好地使用 AI 编程

Day 1 你学会了让 AI 帮你写代码，但还有很多技巧可以让 AI 更好地为你服务：

- AI 编程的底层原理
- 提示词工程：如何更精确地描述需求

- 如何评估 AI 生成的代码质量
- 迭代开发的方法论
- 构建更复杂的项目（AI 智能体）

### Week 2：编程知识深入

要成为一个能独立解决问题的开发者，你需要理解 AI 帮你写的代码背后的知识：

- Git 的更多功能（分支、合并、协作）
- TypeScript 语言深入
- 前端和后端的核心概念
- 数据库设计和 SQL
- 测试、调试、安全、性能
