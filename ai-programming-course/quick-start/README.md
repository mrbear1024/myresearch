# Quick Start — 一天上线

> 目标：在一天之内，从零搭建开发环境，用 AI 构建一个 AI 聊天应用，并部署到线上。

## 你将学到

- 搭建现代 Web 开发环境
- 使用终端和命令行基本操作
- Git 版本控制的最小可用知识
- 用 AI 辅助创建和开发 Next.js 项目
- 接入 Supabase 作为后端
- 部署应用到 Vercel

## 开始之前

确保你有以下账号（都有免费额度）：

- [GitHub](https://github.com) — 代码托管
- [Supabase](https://supabase.com) — 后端服务
- [Vercel](https://vercel.com) — 部署平台
- [OpenAI](https://platform.openai.com) 或 [Anthropic](https://console.anthropic.com) — AI API
