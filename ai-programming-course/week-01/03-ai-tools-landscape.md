# 03 — AI 编程工具全景

> 学习目标：了解主流 AI 编程工具的特点和使用场景，选择适合自己的工具组合。

## 工具分类

AI 编程工具可以分为四大类：

### 1. CLI AI 代理（⭐ 首选）

在终端中直接操作代码库的 AI 工具。**这是我们课程推荐的主力工具。**

#### Claude Code（首选推荐）

- **类型**：Anthropic 官方命令行 AI 代理
- **核心功能**：
  - 直接读写项目文件
  - 运行命令和查看输出
  - 自主完成多步骤任务（创建项目、修改代码、运行测试、修复 bug）
  - 理解整个代码库的上下文
- **适合**：所有开发者，从初学者到专家
- **价格**：按 API 使用量计费
- **为什么推荐**：AI 直接操作代码库，不需要来回复制粘贴，效率最高；同时培养你对终端和项目结构的理解
- **移动端**：Claude Code App 支持手机/平板使用，配置 GitHub 授权后可以随时随地写代码、提 PR、做 code review

#### Codex（备选推荐）

- **类型**：OpenAI 的命令行 AI 代理
- **核心功能**：
  - 类似 Claude Code，在终端中直接操作项目
  - 开源项目，社区活跃
- **适合**：想使用 OpenAI 模型的用户
- **价格**：按 API 使用量计费

### 2. AI 原生编辑器（备选）

在图形编辑器中与 AI 交互。如果你不习惯命令行，可以作为过渡工具。

#### Cursor

- **类型**：基于 VS Code 的 AI 原生编辑器
- **核心功能**：
  - `Cmd+K` — 选中代码后让 AI 修改
  - `Cmd+L` — 打开 AI 聊天面板
  - Tab 补全 — 智能代码补全
  - Composer — 多文件同时修改
- **适合**：不习惯终端操作、需要图形界面的用户
- **价格**：有免费额度，Pro 版 $20/月

#### Windsurf

- **类型**：AI 原生编辑器
- **特点**：类似 Cursor 的竞品，强调 Flows（连续 AI 对话）

### 3. AI 对话工具

在独立界面中与 AI 对话，适合讨论和学习。

#### Claude（Anthropic）

- **特点**：长上下文理解能力强，代码质量高
- **最佳使用场景**：
  - 复杂代码的解释和重构
  - 架构设计讨论
  - 长文档生成

#### ChatGPT（OpenAI）

- **特点**：通用能力强，生态丰富
- **最佳使用场景**：
  - 快速原型和代码片段
  - 学习新概念
  - 代码解释

### 4. 编辑器插件

安装在现有编辑器中的 AI 扩展。

#### GitHub Copilot

- **类型**：VS Code / JetBrains 插件
- **核心功能**：
  - 行内代码补全（像自动完成一样）
  - Copilot Chat 面板
- **适合**：喜欢 VS Code 原生体验，只需要补全功能
- **价格**：$10/月，学生免费

## 如何选择

### 推荐组合（所有用户）

```
Claude Code / Codex（主力工具）+ VS Code（代码浏览）+ Claude / ChatGPT（复杂讨论）
```

理由：CLI AI 代理直接操作代码库，效率最高，同时培养终端能力和对代码的整体理解。

### 备选组合（不习惯终端的用户）

```
Cursor（主力编辑器）+ Claude / ChatGPT（遇到复杂问题时切换）
```

理由：Cursor 提供图形化的 AI 交互体验，学习曲线更平缓。但建议尽早过渡到 CLI 工具。

## 使用场景对照表

| 场景 | 推荐工具 |
|------|---------|
| 写新功能 | Claude Code / Codex |
| 修复 bug | Claude Code / Codex + 错误信息 |
| 理解代码 | Claude / ChatGPT |
| 重构代码 | Claude Code / Codex |
| 学习新概念 | Claude / ChatGPT |
| 代码审查 | Claude Code / Claude（长上下文） |
| 快速原型 | Claude Code / Codex |
| 不习惯终端时 | Cursor |

## 工具使用技巧

### 通用技巧

1. **给足上下文** — 不管用哪个工具，上下文越多越好
2. **验证输出** — AI 生成的代码一定要自己测试
3. **多工具配合** — 不同工具各有所长，灵活切换
4. **保存好用的提示词** — 建立自己的提示词库

### Claude Code / Codex 技巧

- 在项目根目录创建 `CLAUDE.md` 文件，定义项目规则和上下文，AI 会自动读取
- 用自然语言描述需求，AI 会自动分析代码库、编辑文件、运行命令
- 善用 `/` 命令（如 `/help`）查看可用功能

### Cursor 技巧（备选工具）

- 用 `@` 引用文件、文件夹或文档
- 选中代码后 `Cmd+K` 可以针对选中部分提问
- 在 `.cursorrules` 文件中定义项目级别的 AI 规则

## 小结

- **Claude Code / Codex 是首选**：直接在终端操作代码库，效率最高，也能培养你的工程能力
- Cursor 作为备选：适合不习惯终端的用户，但建议尽早过渡到 CLI 工具
- 不同工具各有所长，灵活搭配对话工具（Claude / ChatGPT）处理复杂讨论
- 工具在快速迭代中，保持关注新工具和新功能
