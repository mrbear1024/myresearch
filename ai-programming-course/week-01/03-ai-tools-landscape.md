# 03 — AI 编程工具全景

> 学习目标：了解主流 AI 编程工具的特点和使用场景，选择适合自己的工具组合。

## 工具分类

AI 编程工具可以分为三大类：

### 1. AI 原生编辑器

在编辑器中直接与 AI 交互。

#### Cursor

- **类型**：基于 VS Code 的 AI 原生编辑器
- **核心功能**：
  - `Cmd+K` — 选中代码后让 AI 修改
  - `Cmd+L` — 打开 AI 聊天面板
  - Tab 补全 — 智能代码补全
  - Composer — 多文件同时修改
- **适合**：日常开发，需要 AI 深度参与编码过程
- **价格**：有免费额度，Pro 版 $20/月

#### Windsurf

- **类型**：AI 原生编辑器
- **特点**：类似 Cursor 的竞品，强调 Flows（连续 AI 对话）
- **适合**：想尝试不同 AI 编辑器的用户

### 2. 编辑器插件

安装在现有编辑器中的 AI 扩展。

#### GitHub Copilot

- **类型**：VS Code / JetBrains 插件
- **核心功能**：
  - 行内代码补全（像自动完成一样）
  - Copilot Chat 面板
- **适合**：喜欢 VS Code 原生体验，只需要补全功能
- **价格**：$10/月，学生免费

### 3. AI 对话工具

在独立界面中与 AI 对话，复制粘贴代码。

#### Claude（Anthropic）

- **特点**：长上下文理解能力强，代码质量高
- **最佳使用场景**：
  - 复杂代码的解释和重构
  - 架构设计讨论
  - 长文档生成

#### ChatGPT（OpenAI）

- **特点**：通用能力强，生态丰富
- **最佳使用场景**：
  - 快速原型和代码片段
  - 学习新概念
  - 代码解释

### 4. CLI 工具

在终端中直接使用 AI。

#### Claude Code

- **类型**：命令行 AI 代理
- **核心功能**：
  - 直接读写项目文件
  - 运行命令和查看输出
  - 自主完成多步骤任务
- **适合**：熟悉终端的开发者，复杂的代码修改任务
- **特点**：AI 可以直接操作你的代码库

## 如何选择

### 初学者推荐组合

```
Cursor（主力编辑器）+ Claude / ChatGPT（遇到复杂问题时切换）
```

理由：Cursor 的交互体验最直观，AI 聊天和代码编辑无缝集成。

### 进阶用户推荐组合

```
Cursor / VS Code + Claude Code（CLI）+ Claude（复杂讨论）
```

理由：CLI 工具在自动化和批量修改方面更高效。

## 使用场景对照表

| 场景 | 推荐工具 |
|------|---------|
| 写新功能 | Cursor / Copilot |
| 修复 bug | Cursor + 错误信息 |
| 理解代码 | Claude / ChatGPT |
| 重构代码 | Claude Code / Cursor Composer |
| 学习新概念 | Claude / ChatGPT |
| 代码审查 | Claude（长上下文） |
| 快速原型 | Cursor |

## 工具使用技巧

### 通用技巧

1. **给足上下文** — 不管用哪个工具，上下文越多越好
2. **验证输出** — AI 生成的代码一定要自己测试
3. **多工具配合** — 不同工具各有所长，灵活切换
4. **保存好用的提示词** — 建立自己的提示词库

### Cursor 特有技巧

- 用 `@` 引用文件、文件夹或文档
- 选中代码后 `Cmd+K` 可以针对选中部分提问
- 在 `.cursorrules` 文件中定义项目级别的 AI 规则

## 小结

- 没有"最好的"AI 工具，只有最适合当前场景的
- 初学者从 Cursor 开始是最简单的路径
- 随着经验增长，你会自然地学会组合使用多个工具
- 工具在快速迭代中，保持关注新工具和新功能
