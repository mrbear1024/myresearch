# 02 — 编程提示词工程

> 学习目标：掌握编程场景下的提示词技巧，让 AI 生成更准确、更可用的代码。

## 核心原则

**提示词越具体，AI 输出越准确。**

## 六大技巧

### 1. 明确技术栈

❌ 差的提示：
> "写一个登录页面"

✅ 好的提示：
> "用 Next.js App Router + TypeScript + Tailwind CSS 写一个登录页面，包含邮箱和密码输入框，使用 Supabase Auth 进行认证。"

### 2. 提供上下文

❌ 差的提示：
> "这段代码报错了，怎么修？"

✅ 好的提示：
> "我在 Next.js 项目中运行 `npm run dev` 时遇到以下错误：
> ```
> Error: Cannot find module '@supabase/supabase-js'
> ```
> 我的 package.json 如下：[粘贴]
> 我已经运行过 npm install。"

### 3. 分步骤请求

❌ 差的提示：
> "帮我做一个完整的用户管理系统"

✅ 好的提示：
> "我要做一个用户管理系统，先帮我完成第一步：创建 Supabase 的用户表，包含 id、name、email、avatar_url 和 created_at 字段。请给出 SQL 建表语句。"

### 4. 提供示例

```
"我需要一个自定义 React Hook，用来处理表单状态。
类似这样使用：

const { values, handleChange, handleSubmit } = useForm({
  initialValues: { name: '', email: '' },
  onSubmit: (values) => console.log(values),
});

请实现这个 useForm Hook。"
```

### 5. 指定角色

```
"作为一个资深 Next.js 开发者，请审查以下代码，
指出潜在的性能问题和安全隐患：
[粘贴代码]"
```

### 6. 要求解释

```
"请实现这个功能，并在关键行添加注释，
解释为什么这样写。我是 TypeScript 初学者。"
```

## 调试专用模板

```
【问题描述】
我在做 [什么功能] 时遇到了问题。

【错误信息】
[粘贴完整的错误信息]

【相关代码】
[粘贴出问题的代码]

【已经尝试过的方法】
1. [方法1]
2. [方法2]

【期望的行为】
[描述你期望代码应该如何工作]
```

## 迭代优化提示词

第一次 AI 的回答不完美是正常的。迭代方式：

```
第 1 轮："实现一个聊天消息列表组件"
第 2 轮："消息气泡需要区分用户和 AI 的样式，用户在右边蓝色，AI 在左边灰色"
第 3 轮："加上消息发送时间的显示，格式是 HH:mm"
第 4 轮："消息列表需要自动滚动到最新消息"
```

每一轮都在上一轮的基础上细化。

## 高级技巧

### 让 AI 先思考再编码

```
"在写代码之前，先分析一下实现这个功能有哪几种方案，
各自的优缺点是什么，然后推荐一个最适合我的场景的方案。"
```

### 让 AI 审查自己的代码

```
"请审查你刚才生成的代码，检查是否有：
1. 类型安全问题
2. 错误处理遗漏
3. 性能隐患
4. 安全漏洞"
```

## 小结

- 提示词是你和 AI 之间的接口，投入时间写好提示词是值得的
- 具体 > 模糊，分步 > 一步到位，有上下文 > 无上下文
- 不要期望一次就完美，迭代优化是正常的工作方式
- 随着你编程知识的增长，你的提示词质量也会自然提高
