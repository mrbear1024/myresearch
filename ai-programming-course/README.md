# AI 编程课程 — 用 AI 学编程

> 从零开始，用 AI 辅助编程，快速构建并上线一个真实的软件项目。

## 适合谁

- 编程零基础，但想用 AI 快速构建软件的人
- 有一定基础，想学会如何高效利用 AI 编程工具的开发者
- 对 AI 智能体、AI 应用开发感兴趣的人

## 前置条件

- 一台电脑（Mac / Windows / Linux）
- 稳定的网络连接
- 学习的热情

## 技术栈

| 技术 | 用途 | 为什么选它 |
|------|------|-----------|
| TypeScript | 编程语言 | 类型安全，能帮助 AI 生成更准确的代码 |
| Next.js | 全栈框架 | React 生态，前后端一体，社区庞大 |
| Supabase | 后端服务 | 开源 Firebase 替代，PostgreSQL + 认证 + 实时 |
| Vercel | 部署平台 | 与 Next.js 无缝集成，一键部署 |
| Git | 版本控制 | 行业标准，项目管理必备 |

## 学习路径

```
Quick Start (Day 1)          Week 1                    Week 2
──────────────────          ──────                    ──────
搭建环境                     AI 编程原理               Git 深入
学习 CLI 基础                提示词工程                 TypeScript 基础
Git 最小知识                 AI 工具全景                前端核心
创建项目                     阅读 AI 代码               后端核心
构建 AI 聊天应用             迭代开发                   数据库
接入 Supabase                用 AI 调试                 API 设计
部署到 Vercel                构建 AI 智能体              测试 / 调试 / 部署
                                                       安全 / 性能
目标：一天内上线项目          目标：熟练驾驭 AI 编程       目标：掌握编程基础知识
```

## 课程内容

### [Quick Start — 一天上线](./quick-start/)

从零开始，在一天内搭建开发环境、用 AI 构建一个 AI 聊天应用，并部署上线。

### [Week 1 — AI 辅助编程进阶](./week-01/)

深入理解 AI 编程工具的工作原理，学会提示词技巧和迭代开发方法，构建一个 AI 智能体项目。

### [Week 2 — 编程知识深入](./week-02/)

系统学习编程基础知识：Git、TypeScript、前端、后端、数据库、测试、安全等，为独立开发打下基础。

术语表、速查表、推荐学习资源。
