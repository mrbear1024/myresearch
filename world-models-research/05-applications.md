# 应用领域

## 1. 自动驾驶

**现状**：中国超过80%的自动驾驶算法现在使用世界模型进行辅助训练。

### 主要参与者

| 公司/项目 | 世界模型 | 特点 |
|-----------|----------|------|
| **Waymo** | WWM (2026年2月) | 基于5000万自动驾驶里程的扩散+自回归模型 |
| **Wayve** | GAIA-1/2/3 | 15B参数，9个国家环境，安全验证 |
| **NVIDIA** | Cosmos + Alpamayo | 360度多视角驾驶场景生成 |
| **Tesla** | 端到端世界模型 | 8摄像头，FSD训练的神经网络模拟 |
| **XPENG** | 基于 Cosmos | NVIDIA 生态系统 |
| **Uber** | 基于 NVIDIA | 预计2027年在洛杉矶和旧金山部署 L4 Robotaxi |

### 关键能力
- 生成罕见/高风险场景用于安全测试
- 多智能体交互模拟
- 闭环控制训练
- 合成数据生成减少真实世界数据依赖

## 2. 机器人

### 核心进展
- **V-JEPA 2** (Meta)：仅需62小时机器人数据实现零样本控制
- **RWM** (ETH Zurich)：长周期预测的机器人世界模型
- **MoWM**：基于视频的具身规划
- **GWM** (ICCV 2025)：高斯世界模型用于机器人操作
- **人形机器人世界模型**：专为人形机器人设计的开源基础模型

- 1X (人形机器人)
