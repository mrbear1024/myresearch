## 4.1 电路基础知识

### 4.1.1 用水管类比理解电路

电路可以用水管系统来类比：

| 电学概念 | 水管类比 | 单位 | 符号 |
|----------|----------|------|------|
| **电压 (Voltage)** | 水压（水塔高度） | 伏特 (V) | V 或 U |
| **电流 (Current)** | 水流量 | 安培 (A) | I |
| **电阻 (Resistance)** | 水管粗细 | 欧姆 (Ω) | R |
| **功率 (Power)** | 水流做的功 | 瓦特 (W) | P |

### 4.1.2 欧姆定律

最基本的电路公式：

```
V = I × R        电压 = 电流 × 电阻
I = V / R        电流 = 电压 / 电阻
R = V / I        电阻 = 电压 / 电流
P = V × I        功率 = 电压 × 电流
```

**实际例子**：一个 LED 工作电压 2V，工作电流 20mA，使用 3.3V 电源供电：
- 需要串联一个限流电阻
- 电阻上的电压：3.3V - 2V = 1.3V
- 需要的电阻：R = 1.3V / 0.02A = 65Ω → 选用标准值 68Ω

### 4.1.3 串联与并联

**串联**：元件首尾相连，电流相同，电压分配
- 总电阻 = R1 + R2 + R3
- 应用：LED 限流电阻、分压电路

**并联**：元件两端分别相连，电压相同，电流分配
- 总电阻 = 1 / (1/R1 + 1/R2 + 1/R3)
- 应用：多个 LED 并联、电源并联增大电流

### 4.1.4 直流 (DC) 与交流 (AC)

| 特性 | 直流 (DC) | 交流 (AC) |
|------|-----------|-----------|
| 电流方向 | 固定不变 | 周期性变化 |
| 常见来源 | 电池、USB、电源适配器输出 | 市电（220V/50Hz） |
| 在硬件产品中 | 电路板上基本都是直流 | 需要通过电源适配器转换为直流 |

> **重点**：硬件产品内部基本都是直流电路。常见的工作电压：3.3V、5V、12V。

## 4.2 常用电子元器件

### 4.2.1 无源器件（被动元件）

#### 电阻 (Resistor)

- **作用**：限制电流、分压、上拉/下拉
- **单位**：欧姆 (Ω)，常用 kΩ（千欧）、MΩ（兆欧）
- **常用封装**：0402（1.0×0.5mm）、0603（1.6×0.8mm）
- **精度**：5%（一般用途）、1%（精密电路）
- **价格**：约 ¥0.005/个（批量）

#### 电容 (Capacitor)

- **作用**：滤波（去除噪声）、储能、耦合/隔直
- **单位**：法拉 (F)，常用 pF、nF、μF
- **类型**：
  - 陶瓷电容（MLCC）：最常用，小体积
  - 电解电容：大容量，有极性（正负极不能接反）
  - 钽电容：稳定性好，价格较高
- **常用值**：100nF（去耦）、10μF（电源滤波）、22pF（晶振匹配）

#### 电感 (Inductor)

- **作用**：滤波、储能（DC-DC电路中）
- **单位**：亨利 (H)，常用 μH、mH
- **应用**：主要在电源电路中使用

### 4.2.2 半导体器件

#### 二极管 (Diode)

- **特性**：单向导通（电流只能从正极流向负极）
- **常见类型**：
  - 整流二极管：交流转直流
  - 肖特基二极管：低正向压降，常用于电源
  - 稳压二极管（Zener）：稳定电压
  - **LED（发光二极管）**：发光指示

#### 三极管 (Transistor) 和 MOS管 (MOSFET)

- **作用**：电子开关、信号放大
- **区别**：
  - 三极管 (BJT)：电流驱动，适合小信号
  - MOS管 (MOSFET)：电压驱动，开关速度快，适合驱动负载
- **常用场景**：LED驱动、电机驱动、电源开关

### 4.2.3 集成电路 (IC)

#### MCU — 微控制器

产品的"大脑"，运行你编写的固件程序。（详见 4.5 节）

#### 传感器芯片

将物理量转换为电信号：
| 传感器类型 | 常用芯片 | 测量范围 | 接口 | 单价 |
|-----------|---------|---------|------|------|
| 温湿度 | SHT30 | -40~125°C, 0-100%RH | I2C | ¥5-8 |

| 空气质量 | SGP30 | TVOC/eCO2 | I2C | ¥15-25 |

#### 电源管理芯片

## 4.3 如何读懂电路原理图

### 4.3.1 常用原理图符号

```
电阻：    ─[///]─     或  ─[   ]─ (方块符号)
电容：    ─||─        或  ─|├─
电感：    ─(((─
二极管：  ─|>|─       (三角形+竖线)
LED：     ─|>|─ →→    (带箭头表示发光)
三极管：  有 B(基极), C(集电极), E(发射极) 三个引脚
MOS管：   有 G(栅极), D(漏极), S(源极) 三个引脚
MCU：     大方块，标注所有引脚名称和编号
```

### 4.3.2 电源符号

```
VCC / VDD / V+     —— 正电源（3.3V或5V）
GND / VSS / V-     —— 地（0V参考点）
VBAT               —— 电池电压
3V3                 —— 3.3V电源
5V                  —— 5V电源
```

### 4.3.3 读图方法

1. **先看电源部分**：找到电源输入和各路电压的产生
2. **找到主控 MCU**：看它连接了哪些外设
3. **按模块阅读**：传感器模块、通信模块、电源模块分别理解
4. **注意网络标号**：相同名称的网络标号表示电气连接（即使在图上画得很远）

## 4.4 常见电路模块

### 4.4.1 电源电路

**LDO 稳压电路（5V → 3.3V）**：

```
5V ──[AMS1117-3.3]── 3.3V
      │    │    │
     C1   GND  C2
    10μF       10μF
```

简单可靠，适合电流 < 800mA 的场景。缺点是效率低（发热）。

**USB Type-C 供电电路**：

USB Type-C 输入 5V → LDO/DC-DC → 3.3V 给 MCU 供电

### 4.4.2 传感器电路

以 SHT30 温湿度传感器为例（I2C 接口）：

```
3.3V ── VDD (SHT30)
         │
        C1 (100nF 去耦电容)
         │
GND  ── GND (SHT30)
         
MCU_SDA ──[4.7kΩ上拉]── 3.3V
         │
SHT30_SDA

MCU_SCL ──[4.7kΩ上拉]── 3.3V
         │
SHT30_SCL
```

I2C 总线需要上拉电阻（通常 4.7kΩ）。

### 4.4.3 LED 指示灯电路

```
MCU_GPIO ──[68Ω]──|>|── GND
                  LED
```

MCU GPIO 输出高电平时 LED 亮，低电平时 LED 灭。

### 4.7.2 开发环境搭建（Arduino IDE）

1. 下载安装 Arduino IDE 2.x
2. 添加 ESP32 开发板支持：
   - 打开 文件 → 首选项
   - 在"附加开发板管理器网址"中添加：
   ```

   ```
3. 打开 工具 → 开发板 → 开发板管理器，搜索 `esp32` 并安装
4. 选择对应的开发板型号
5. 选择正确的串口

### 4.7.3 第一个程序：Blink（LED闪烁）

```c
// ESP32 板载LED闪烁
// 大多数 ESP32 开发板的板载LED连接在 GPIO2

#define LED_PIN 2

void setup() {
  pinMode(LED_PIN, OUTPUT);  // 设置 GPIO2 为输出模式
  Serial.begin(115200);       // 初始化串口，波特率115200
  Serial.println("Hello, Hardware World!");
}

void loop() {
  digitalWrite(LED_PIN, HIGH);  // LED亮
  Serial.println("LED ON");
  delay(1000);                  // 等待1秒

  digitalWrite(LED_PIN, LOW);   // LED灭
  Serial.println("LED OFF");
  delay(1000);                  // 等待1秒
}
```

上传步骤：
1. 用 USB 线连接 ESP32 到电脑
2. 在 Arduino IDE 中选择正确的开发板和串口
3. 点击"上传"按钮（→箭头）
4. 等待编译和上传完成
5. 观察开发板上 LED 是否每秒闪烁一次
6. 打开串口监视器（波特率115200）查看打印信息

### 4.7.4 读取温湿度传感器（DHT22）

**接线**：

| DHT22 引脚 | 连接到 |
|------------|--------|
| VCC（红线） | ESP32 3.3V |
| DATA（黄线） | ESP32 GPIO4 |
| GND（黑线） | ESP32 GND |

DATA 引脚需要一个 10kΩ 上拉电阻到 VCC（很多模块已经内置）。

**安装库**：Arduino IDE → 库管理器 → 搜索 `DHT sensor library` 并安装

**代码**：

```c
#include "DHT.h"

#define DHTPIN 4       // DHT22 数据引脚连接到 GPIO4
#define DHTTYPE DHT22  // 传感器类型

DHT dht(DHTPIN, DHTTYPE);

void setup() {
  Serial.begin(115200);
  Serial.println("DHT22 温湿度传感器测试");
  dht.begin();
}

void loop() {
  delay(2000);  // DHT22 每2秒才能读取一次

  float humidity = dht.readHumidity();       // 读取湿度
  float temperature = dht.readTemperature(); // 读取温度(摄氏)

  // 检查是否读取失败
  if (isnan(humidity) || isnan(temperature)) {
    Serial.println("读取传感器失败！请检查接线。");
    return;
  }

  // 计算体感温度
  float heatIndex = dht.computeHeatIndex(temperature, humidity, false);

  Serial.print("湿度: ");
  Serial.print(humidity);
  Serial.print(" %\t");
  Serial.print("温度: ");
  Serial.print(temperature);
  Serial.print(" °C\t");
  Serial.print("体感温度: ");
  Serial.print(heatIndex);
  Serial.println(" °C");
}
```

上传后打开串口监视器，你应该能看到每2秒更新一次的温湿度数据。
