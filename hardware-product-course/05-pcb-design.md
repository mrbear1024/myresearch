## 5.1 PCB 基础概念

### 5.1.1 什么是 PCB？

PCB（Printed Circuit Board，印刷电路板）是电子产品的"骨架"，用来承载和连接电子元器件。

**从面包板到 PCB 的进化**：

| 阶段 | 形式 | 优点 | 缺点 | 适用 |
|------|------|------|------|------|
| 面包板 | 免焊接插板 | 快速搭建、可反复修改 | 接触不可靠、体积大 | 概念验证 |
| 洞洞板 | 手工焊接万能板 | 比面包板可靠 | 走线凌乱、不美观 | 单件调试 |
| **PCB** | 定制印刷电路板 | 可靠、美观、可量产 | 需要设计、修改有成本 | **产品级** |

### 5.1.2 PCB 的基本结构

一块 PCB 由多层结构组成（从上到下）：

```
丝印层 (Silkscreen)     —— 白色文字和标识
阻焊层 (Solder Mask)    —— 绿色（或其他颜色）保护层
铜层 (Copper Layer)      —— 导电线路
基材 (Substrate/FR-4)    —— 玻璃纤维环氧树脂板
铜层 (Copper Layer)      —— 底面导电线路
阻焊层 (Solder Mask)    —— 底面保护层
丝印层 (Silkscreen)     —— 底面文字标识
```

### 5.1.3 PCB 层数选择

| 层数 | 结构 | 成本 | 适用场景 | 打样价格(5片) |
|------|------|------|----------|---------------|
| **单面板** | 1层铜 | 最低 | LED灯板、简单电路 | ¥2-5 |
| **双面板** | 2层铜 | 低 | 大多数消费电子产品 | ¥5-20 |
| **四层板** | 4层铜 | 中等 | 高速信号、复杂产品 | ¥50-100 |
| **六层板** | 6层铜 | 较高 | 高密度、专业设备 | ¥150-300 |

> **建议**：大多数 IoT 产品和消费电子用**双面板**就够了。只有高速信号（如 USB 3.0、HDMI）或非常复杂的设计才需要四层板。

## 5.3 原理图设计流程

### 5.3.1 设计流程概览

```
需求分析 → 模块划分 → 元器件选型 → 绘制原理图 → 电气规则检查(ERC) → 生成网表
```

### 5.3.2 实操步骤（立创EDA）

**第1步：创建工程**
- 打开立创EDA，新建工程
- 工程中包含：原理图(.sch) + PCB(.pcb)

**第2步：模块化设计**

将电路按功能分成独立的模块，每个模块在原理图中占据一个区域：

| 模块 | 包含内容 |
|------|----------|
| 电源模块 | USB输入、LDO、滤波电容 |
| MCU模块 | ESP32及其最小系统（晶振、复位、Flash） |
| 传感器模块 | SHT30、BMP280及I2C上拉 |
| 显示模块 | OLED屏幕接口 |
| 用户交互 | 按键、LED |
| 电池管理 | 充电芯片、电池连接器 |

**第3步：放置元器件**
- 从元件库中搜索并放置元器件
- 立创EDA可以直接搜索立创商城编号

**第4步：连线**
- 用导线(Wire)连接各元器件引脚
- 使用网络标号(Net Label)连接不同区域的信号
- 电源引脚使用电源符号(VCC/GND)

**第5步：电气规则检查（ERC）**
- 运行 ERC 检查
- 修复所有错误（未连接引脚、短路等）
- 警告可以根据情况判断是否需要处理

**第6步：生成网表**
- 原理图完成后，生成网表导入 PCB 编辑器

## 5.4 PCB 布局布线基础规则

### 5.4.1 元器件摆放原则

1. **按模块分区**：电源区、MCU区、传感器区等明确分区
2. **信号流向**：输入在左/上，输出在右/下，信号从输入流向输出
3. **去耦电容靠近芯片**：每个IC的电源引脚旁放置100nF去耦电容，越近越好
4. **发热器件分散放置**：LDO、电源芯片远离温度传感器
5. **连接器放在板边**：USB、电池座等放在PCB边缘，方便插拔
6. **考虑装配**：同类元件方向一致，方便SMT贴片

### 5.4.2 走线规则

| 规则 | 说明 | 建议值 |
|------|------|--------|
| **线宽** | 信号线 | 0.2-0.3mm |
| **线宽** | 电源线 | 0.5-1.0mm（视电流而定） |
| **线间距** | 相邻走线最小间距 | ≥ 0.15mm（嘉立创最小） |
| **过孔** | 走线从正面到背面 | 外径0.6mm / 孔径0.3mm |
| **避免锐角** | 走线转弯 | 使用45°角或圆弧 |
| **避免直角** | 走线不要90°直角转弯 | 会造成阻抗不连续 |

**电流与线宽对照**（外层，1oz铜厚）：

| 电流 | 建议线宽 |
|------|----------|
| < 0.3A | 0.2mm |
| 0.3-0.5A | 0.3mm |
| 0.5-1A | 0.5mm |
| 1-2A | 1.0mm |
| 2-3A | 1.5mm |

### 5.4.3 接地设计

- **铺铜接地**：在PCB空白区域铺铜连接到GND，提供良好的接地回路
- **地线尽量粗**：减小地线阻抗
- **模拟地与数字地**：如果有高精度模拟电路，考虑分地后单点连接

### 5.4.4 安装孔与板框

- **安装孔**：常用M2（孔径2.2mm）或M3（孔径3.2mm）
- **板框**：在 PCB 编辑器中绘制板子的外形轮廓
- **板框圆角**：建议所有直角倒圆角R1mm以上，避免扎手
- **定位孔**：用于工厂生产时的定位（Mark点）

## 5.5 电源设计基础

### 5.5.1 LDO 电源设计要点

```
电源输入 ──[保护二极管]──┬──[C1 10μF]──┬──[AMS1117-3.3]──┬──[C2 10μF]──┬── 3.3V输出
                         │              │                  │              │
                        GND            GND                GND            GND
```

关键点：
- 输入端和输出端都需要滤波电容
- LDO输入电压不要超过规格书最大值
- 注意LDO的压差（Dropout Voltage），输入至少比输出高0.3V以上
- 注意散热：(Vin-Vout) × Iload = 发热功率

### 5.5.2 DC-DC 电源布局

DC-DC 开关电源比 LDO 效率高但电路更复杂，布局要求更严格：

1. 输入电容尽量靠近芯片 VIN 引脚
2. 电感尽量靠近芯片 SW 引脚
3. 输出电容靠近负载
4. 反馈电阻靠近芯片 FB 引脚
5. SW 节点的走线面积尽量小（减少EMI辐射）
6. 接地走线要短且粗

## 5.6 PCB 打样实操

### 5.6.1 国内主流打样平台

| 平台 | 特点 | 最低价格 | 发货速度 |
|------|------|----------|----------|
| **嘉立创 (JLCPCB)** | 最便宜、最快、SMT一站式 | 5片双面板 ¥2 | 24小时发货 |
| **捷配 (JIEPC)** | 品质好、服务好 | 5片双面板 ¥10 | 24-48小时 |
| **华秋 (HQ PCB)** | 品质高、适合中高端 | 5片双面板 ¥30 | 48小时 |

> 学习和打样阶段推荐**嘉立创**，价格极低。

### 5.6.2 打样参数选择

| 参数 | 推荐值 | 说明 |
|------|--------|------|
| 层数 | 2层 | 双面板满足大多数需求 |
| 板厚 | 1.6mm | 标准厚度 |
| 铜厚 | 1oz (35μm) | 标准铜厚 |
| 阻焊颜色 | 绿色 | 最便宜，其他颜色加价 |
| 丝印颜色 | 白色 | 标准 |
| 表面工艺 | HASL（有铅喷锡） | 最便宜；无铅喷锡或沉金加价 |
| 最小线宽/间距 | 6/6mil | 标准工艺 |

### 5.6.3 下单流程

1. 在 PCB 设计软件中导出 **Gerber 文件**（立创EDA可一键下单，无需导出）
2. 上传 Gerber 到打样平台
3. 平台自动解析并预览，确认无误
4. 选择参数、数量，下单付款
5. 等待生产和发货（嘉立创最快24小时）

### 5.6.4 嘉立创 SMT 一站式服务

嘉立创提供 PCB + SMT 一体服务：
- 上传 PCB 设计文件和 BOM
- 平台自动匹配立创商城库存
- 完成贴片焊接后发货
- 小批量 SMT 起步费约 ¥50-100

## 5.7 DFM（可制造性设计）要点

DFM = Design for Manufacturing，在设计阶段就考虑制造的可行性和效率。

### 关键 DFM 规则

| 项目 | 要求 | 说明 |
|------|------|------|
| 最小线宽 | ≥ 6mil (0.15mm) | 常规工艺，高密度可到4mil |
| 最小间距 | ≥ 6mil (0.15mm) | 走线间、焊盘间 |
| 最小过孔 | 孔径 ≥ 0.3mm | 常规工艺 |
| 焊盘到板边距离 | ≥ 0.3mm | 防止铣板时损伤焊盘 |
| 铜箔到板边距离 | ≥ 0.2mm | 同上 |
| Mark点 | 至少2个 | SMT贴片定位用 |
| 拼板间距 | V-CUT: 0mm, 邮票孔: ≥ 1.6mm | 拼板工艺 |

### 常见 DFM 问题

1. **焊盘太小或间距太窄**：导致焊接不良
2. **缺少 Mark 点**：SMT 机器无法定位
3. **板框不规则**：增加制造难度和成本
4. **丝印压焊盘**：影响焊接质量
5. **阻焊开窗不合理**：可能导致短路

## 5.8 Gerber 文件与 BOM 管理

### Gerber 文件

Gerber 是 PCB 制造的标准文件格式。一套完整的 Gerber 包含：

| 文件层 | 说明 |
|--------|------|
| Top Copper (GTL) | 顶层铜线路 |
| Bottom Copper (GBL) | 底层铜线路 |
| Top Solder Mask (GTS) | 顶层阻焊 |
| Bottom Solder Mask (GBS) | 底层阻焊 |
| Top Silkscreen (GTO) | 顶层丝印 |
| Bottom Silkscreen (GBO) | 底层丝印 |
| Board Outline (GKO) | 板框 |
| Drill File (DRL) | 钻孔文件 |

> **使用立创EDA的便利**：如果使用嘉立创打样，可以直接在立创EDA中一键下单，无需手动导出 Gerber。

### BOM 管理

生产需要两份关键文件：
1. **BOM（物料清单）**：列出所有元器件型号和数量
2. **坐标文件（Pick & Place）**：记录每个元器件的位置和角度，供 SMT 机器使用

两份文件都可以从 PCB 设计软件中导出。

## 5.9 案例：「智能环境监测器」PCB 设计要点

### 板子规格

- 尺寸：50mm × 40mm（根据外壳大小确定）
- 层数：双面板
- 板厚：1.0mm（省空间）

### 布局策略

```
┌─────────────────────────────┐
│  [USB-C]  [充电芯片] [电池座] │  ← 电源区（顶部）
│                               │
│     [ESP32-C3]                │  ← 主控区（中部）
│                               │
│  [SHT30] [BMP280] [BH1750]   │  ← 传感器区（底部，远离发热元件）
│                               │
│  [OLED屏幕连接器]  [按键]     │  ← 交互区
└─────────────────────────────┘

安装孔: 四角各一个 M2 孔
```

### 注意事项

1. 温湿度传感器 SHT30 远离 LDO 等发热源
2. USB-C 连接器放在板边，方便充电
3. OLED 屏幕接口位置与外壳开窗对齐
4. 电池连接器固定牢靠（加焊盘固定脚）

## 5.10 实践练习

### 练习：用立创 EDA 设计一块 LED 闪灯板

设计一块简单的 PCB：ESP32-C3 最小系统 + 1个LED + 1个按键

**步骤**：
1. 注册立创EDA账号
2. 创建新工程
3. 绘制原理图：ESP32-C3模组 + USB Type-C + LED + 按键 + 电源
4. 运行 ERC 检查
5. 转换到 PCB 编辑器
6. 摆放元器件，完成布线
7. 运行 DRC（设计规则检查）
8. 导出 Gerber 或直接下单嘉立创打样

**预期成果**：一块能通过 USB 供电、按键控制 LED 闪烁的小板子。
