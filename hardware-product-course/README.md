# 硬件产品开发课程：从零到第一件产品落地

> 一份面向零基础创业者和独立开发者的实战课程，带你走完从创意到量产上市的完整旅程。

## 课程简介

这门课程专为**没有硬件背景**但想要开发实体产品的人设计。无论你是软件工程师想拓展到硬件领域，还是创业者想把产品创意变为现实，这门课程都将为你提供从零开始的完整路线图。

我们不会深入每一个领域的学术细节，而是聚焦于**实际做出一款硬件产品所需要知道的一切**——包括技术、商务、供应链和项目管理。

## 目标受众

- 有产品创意但不知从何开始的创业者
- 想从软件转向硬件的开发者
- 对智能硬件/IoT 感兴趣的技术爱好者
- 想了解硬件产品开发全貌的产品经理

## 推荐学习顺序

### 路径一：完整学习（推荐）

按章节顺序从第1章到第12章依次学习，适合时间充裕、希望全面掌握的学习者。

### 路径二：快速上手

1. **第1章** → 了解全貌
2. **第4章** → 电子基础
3. **第7章** → 固件开发
4. **第9章** → 动手做原型

先做出一个能工作的原型，再回头补充其他章节的知识。

### 路径三：创业者路径

1. **第1章** → 了解全貌
2. **第2章** → 预算规划
3. **第3章** → 找到合作方
4. **第10-12章** → 认证、量产、上市

侧重商业和供应链，技术部分可以找外包团队完成。

## 课程特色

- **全中文实战导向**：所有内容基于中国供应链生态，工厂、平台、工具都是国内可直接使用的
- **从零开始**：不假设任何硬件背景，每个概念都从基础讲起
- **项目贯穿**：以「智能环境监测器」为贯穿项目，每章都有对应的实践任务
- **成本意识**：每个选择都标注费用，帮你在预算内做出最优决策
