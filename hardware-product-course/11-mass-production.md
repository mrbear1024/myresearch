## 11.1 从原型到量产的转变

### 为什么不能直接用原型的设计量产？

| 原型 | 量产 |
|------|------|
| 手工焊接可以修修补补 | 机器贴片要求设计完美 |
| 3D打印外壳精度够用 | 注塑件需要考虑模具工艺 |
| 一两台可以自己测试 | 上千台需要自动化测试 |
| 用排针调试方便 | 量产版去掉调试接口 |
| 散件采购小批量 | 批量采购需要备料周期 |

### 量产前的设计优化

#### DFM — 可制造性设计

| 优化项 | 原型设计 | 量产优化 |
|--------|----------|----------|
| PCB尺寸 | 随意 | 标准化，方便拼板 |
| 元器件封装 | 混合 | 统一，减少换料时间 |
| 调试接口 | 外露排针 | 测试点（Test Point） |
| 固件烧录 | USB手动烧录 | 烧录治具批量烧录 |
| 标识 | 手写 | 丝印+激光打标+条码 |

#### DFA — 可装配性设计

- 减少螺丝数量（能卡扣就不用螺丝）
- 零件自定位（防呆设计，组装时只能按正确方向安装）
- 减少组装步骤
- 线材连接改为连接器（减少焊接）

## 11.3 SMT 贴片流程

SMT（Surface Mount Technology，表面贴装技术）是现代电子产品制造的核心工艺。

### 完整流程

```
来料检验 → 钢网制作 → 锡膏印刷 → SPI检测 → 贴片 → 回流焊 → AOI检测
→ 手工焊接(插件) → 清洗(可选) → ICT/FCT测试 → 合格入库
```

### 各环节详解

#### 1. 钢网制作

钢网（Stencil）用于将锡膏精确印刷到PCB焊盘上。

| 参数 | 说明 |
|------|------|
| 厚度 | 0.1-0.15mm（常用0.12mm） |
| 材质 | 不锈钢 |
| 制作方式 | 激光切割 |
| 费用 | ¥100-300/张 |

#### 2. 锡膏印刷

通过钢网将锡膏印刷到PCB的焊盘上。

**品质关键**：锡膏量均匀、无偏移、无少锡/多锡。

#### 3. SPI 检测（锡膏检测）

使用 SPI（Solder Paste Inspection）设备检查锡膏印刷质量。

#### 4. 贴片 (Pick & Place)

高速贴片机将元器件从料带上取出，精确放置到PCB上。

| 设备参数 | 说明 |
|----------|------|
| 贴片速度 | 20,000-80,000 CPH（每小时元件数） |
| 精度 | ±0.05mm |
| 最小元件 | 0201（0.6×0.3mm） |

#### 5. 回流焊 (Reflow Soldering)

PCB通过回流焊炉，经历预热→升温→回流→冷却四个阶段，锡膏熔化形成焊点。

```
温度曲线（典型无铅焊接）：

250°C ┤          ╭───╮        回流区(峰值230-250°C)
200°C ┤     ╭────╯   ╰───╮   
150°C ┤  ╭──╯              ╰──╮  保温区(150-200°C)
100°C ┤╭─╯                    ╰──  冷却
 25°C ┤╯
      └────────────────────────── 时间(4-5分钟)
        预热    保温   回流  冷却
```

#### 6. AOI 检测（自动光学检测）

AOI（Automated Optical Inspection）通过摄像头自动检查焊接质量。

检测内容：缺件、偏移、多锡、少锡、桥连、立碑等缺陷。

#### 7. 手工焊接

插件元器件（如 USB 座、排针、大电容等）需要手工焊接或波峰焊。

## 11.4 组装与测试

### 组装流程设计

典型的组装产线：

```
工位1: 烧录固件 → 工位2: 功能测试 → 工位3: 装入外壳 → 工位4: 合壳+打螺丝
→ 工位5: 整机测试 → 工位6: 贴标签 → 工位7: 包装 → 工位8: 装箱
```

### 测试治具

测试治具（Test Fixture/Jig）是量产测试的关键工装。

**功能测试治具**通常包含：
- 弹簧顶针（Pogo Pin）接触PCB测试点
- 测试程序控制板（通常用另一个MCU）
- 状态指示（LED：绿=PASS，红=FAIL）
- 条码扫描枪（记录每台产品测试结果）

**治具费用**：¥2,000-10,000，视复杂度而定。

### 固件烧录方案

| 方式 | 速度 | 成本 | 适合 |
|------|------|------|------|
| USB 手动烧录 | 慢（2-3分钟/台） | ¥0 | < 100台 |
| 烧录治具 | 快（10-30秒/台） | ¥1,000-5,000 | 100-10,000台 |
| 在线烧录（ICT） | 最快 | 编程费 | > 10,000台 |
| 预烧录Flash芯片 | — | 芯片厂代烧 | 大批量 |

## 11.5 品质管理体系

### 三大检验环节

```
供应商 → [IQC来料检验] → 仓库 → 生产线 → [IPQC过程检验] → [OQC成品检验] → 出货
```

### 11.5.1 IQC — 来料检验

| 检验内容 | 方法 |
|----------|------|
| 外观检查 | 目视检查包装、标签、外观 |
| 数量核对 | 清点数量 |
| 规格确认 | 核对型号、参数 |
| 功能抽检 | 关键物料做功能测试 |

**AQL 抽样标准**（GB/T 2828.1）：

| 批量大小 | 抽样数 | AQL 1.0(严格) | AQL 2.5(一般) |
|----------|--------|--------------|--------------|
| 50-90 | 8 | Ac=0, Re=1 | Ac=0, Re=1 |
| 91-150 | 13 | Ac=0, Re=1 | Ac=1, Re=2 |
| 151-280 | 20 | Ac=0, Re=1 | Ac=1, Re=2 |
| 281-500 | 32 | Ac=1, Re=2 | Ac=2, Re=3 |
| 501-1200 | 50 | Ac=1, Re=2 | Ac=3, Re=4 |

> Ac = 接收数（允许的不良品数），Re = 拒收数

### 11.5.2 IPQC — 过程检验

生产过程中的巡检：
- 首件检验（每批次第一件产品详细检查）
- 巡回检验（每隔一段时间抽检）
- 末件检验（批次最后几件检查）

### 11.5.3 OQC — 成品检验

出货前的最终检验：
- 外观检查（划痕、脏污、标签）
- 功能测试（开机、连接、传感器）
- 包装检查（配件齐全、说明书、保修卡）
- 跌落测试（包装状态跌落）

## 11.6 良率管理

### 良率目标

| 阶段 | 良率目标 | 说明 |
|------|----------|------|
| PVT 试产 | > 90% | 首次试产，发现问题 |
| MP 首批 | > 95% | 可接受的起点 |
| MP 成熟期 | > 98% | 稳定量产 |
| 优秀水平 | > 99.5% | 成熟产品 |

### 良率计算

```
良率 = 合格品数量 / 总生产数量 × 100%

直通率(FPY) = 一次性通过所有测试的数量 / 总数量 × 100%
```

### 不良品处理

| 等级 | 定义 | 处理方式 |
|------|------|----------|
| A类（致命） | 安全隐患、功能完全失效 | 报废 |
| B类（严重） | 核心功能异常 | 返工修复 或 报废 |
| C类（一般） | 外观瑕疵、小功能异常 | 返工修复 |

### 8D 报告

当出现批量性品质问题时，使用 8D 方法分析和解决：

| 步骤 | 内容 |
|------|------|
| D1 | 成立团队 |
| D2 | 问题描述 |
| D3 | 临时措施（防止不良品流出） |
| D4 | 根本原因分析 |
| D5 | 制定纠正措施 |
| D6 | 实施纠正措施 |
| D7 | 预防再发 |
| D8 | 总结和关闭 |

## 11.7 包装设计与物流

### 包装层级

```
产品 → 内包装（PE袋/气泡膜） → 彩盒（含说明书/配件） → 外箱（瓦楞纸箱，多台装）
```

### 彩盒设计

| 项目 | 说明 |
|------|------|
| 材质 | 350g白卡纸 + 覆膜 |
| 印刷 | CMYK四色印刷 |
| 工艺 | 覆哑膜/亮膜、烫金/烫银（可选） |
| 费用 | ¥3-8/个（1000个起） |
| 设计 | 自己设计（Canva/AI）或找设计师（¥500-2,000） |

### 内包装设计

| 方案 | 适用 | 成本 |
|------|------|------|
| 珍珠棉内托 | 简单产品 | ¥0.5-2/个 |
| 吸塑内托 | 中端产品 | ¥1-3/个（含模具¥2,000-5,000） |
| EVA内托 | 高端产品 | ¥3-8/个（含模具¥3,000-8,000） |

### 外箱规范

- 标准外箱：五层瓦楞纸箱
- 标注：产品名称、数量、毛重/净重、尺寸、生产日期
- 唛头（Shipping Mark）：收货方信息

### 物流方式

| 方式 | 适用 | 时效 | 成本 |
|------|------|------|------|
| 快递 | < 100台 | 1-3天 | 较高 |
| 物流专线 | 100-1000台 | 3-7天 | 中等 |
| 整车物流 | > 1000台 | 3-7天 | 最低 |
| 海运（出口） | 大批量出口 | 20-40天 | 最低 |

## 11.8 库存管理基础

### 安全库存

```
安全库存 = 日均销量 × (最长交货周期 - 平均交货周期)

示例：日均销量20台，平均交货周期15天，最长可能25天
安全库存 = 20 × (25-15) = 200台
```

### 库存管理原则

| 原则 | 说明 |
|------|------|
| **FIFO** | 先进先出，先入库的先出库 |
| **定期盘点** | 每月盘点实物与账目是否一致 |
| **温湿度管控** | 电子产品避免高温高湿 |
| **防静电** | 敏感器件需防静电包装和存储 |
| **物料保质期** | 锡膏6个月、部分IC有存储时限 |

## 11.9 首批量产常见问题

| 序号 | 问题 | 原因 | 预防措施 |
|------|------|------|----------|
| 1 | 物料短缺，部分料号买不到 | 未提前备料 | 下单前确认所有物料交期和库存 |
| 2 | SMT贴片偏移/虚焊 | 焊盘设计不合理 | 做DFM检查，按推荐焊盘设计 |
| 3 | 注塑件缩水/变形 | 壁厚不均匀 | 设计时壁厚均匀，加强筋合理 |
| 4 | 组装困难，零件对不齐 | 公差累积 | 合理设计公差，预留间隙 |
| 5 | 测试良率低 | 测试标准过严或设计余量不足 | 合理设定测试标准，设计留余量 |
| 6 | 固件Bug在批量时才暴露 | 测试不充分 | PVT阶段充分测试 |
| 7 | 包装保护不足，运输损坏 | 包装设计不合理 | 做跌落测试验证包装 |
| 8 | 丝印/标签印错 | 校对不仔细 | 多人交叉校对 |
| 9 | 颜色与样品不一致 | 批次差异 | 提供色板对照，首件确认 |
| 10 | 交期延误 | 模具修改、物料延迟 | 预留缓冲时间 |
