## 3.1 中国硬件产业带地图

中国拥有全球最完整的硬件制造供应链。不同地区有不同的产业集群特色：

### 核心产业带

| 地区 | 核心产业 | 代表企业/市场 | 特点 |
|------|----------|---------------|------|
| **深圳** | 电子产品、PCB/SMT、消费电子 | 华强北、南山科技园 | 电子产业最完整的城市，从芯片到成品一站式 |
| **东莞** | 模具、注塑、组装代工 | 长安镇（模具之都）、厚街 | 制造业基地，工厂密集，配套成熟 |
| **宁波/温州** | 五金、塑料、小家电 | 慈溪（家电之都） | 小家电和日用品制造中心 |
| **中山/佛山** | 灯具、小家电、五金 | 古镇（灯饰之都） | 照明和小家电制造聚集地 |
| **昆山/苏州** | 精密制造、半导体封装 | 昆山开发区 | 高端制造，外资工厂多 |
| **厦门/泉州** | LED封装、卫浴、鞋服 | — | 特色产业集群 |

### 深圳：硬件创业者的天堂

深圳是全球硬件创业者的首选城市，原因：

1. **华强北**：全球最大的电子元器件集散地，几乎能买到任何电子元件
2. **方案公司密集**：数千家方案公司（Design House），覆盖几乎所有品类
3. **PCB/SMT工厂众多**：从小批量到大批量，各种规模的工厂都有
4. **快速迭代**：上午设计、下午打样、晚上测试，全球最快的硬件迭代速度
5. **完整生态**：设计→打样→认证→量产→物流，一城搞定

> **建议**：如果你做电子类硬件产品，建议至少去深圳实地考察一次。华强北逛一圈，你对元器件和方案的理解会提升一个层次。

## 3.2 找工厂的渠道与方法

### 3.2.1 线上平台

#### 1688（阿里巴巴旗下B2B平台）

**最常用的找工厂平台**，适合国内采购。

- **搜索技巧**：
  - 搜索"产品类型 + 加工"或"产品类型 + 定制"
  - 筛选条件：实力商家 > 行业经验 > 成交额
  - 查看工厂的"实力档案"，包含营业执照、工厂实拍等
- **优点**：供应商数量巨大，价格透明，支持在线交易
- **缺点**：鱼龙混杂，需要仔细甄别
- **适用**：元器件采购、PCB打样、注塑件、包装等

#### 阿里巴巴国际站（Alibaba.com）

适合找有出口经验的工厂，英文界面。很多工厂在1688和国际站都有店铺。

#### 立创商城（LCSC）

电子元器件采购专业平台，价格透明，品质有保障。适合 BOM 配单和小批量元器件采购。

### 3.2.2 线下市场

#### 华强北电子市场

地址：深圳市福田区华强北路

主要市场：
| 市场名称 | 主营品类 | 特点 |
|----------|----------|------|
| 华强电子世界 | IC芯片、MCU | 芯片种类最全 |
| 赛格电子市场 | 元器件、模块、开发板 | 综合性最强 |
| 都会电子城 | 连接器、线材 | 连接器种类丰富 |
| 明通数码城 | 手机配件、屏幕 | 手机配件为主 |

**逛华强北的技巧**：
1. 提前准备好你需要的元器件清单（型号、数量）
2. 多问几家对比价格
3. 注意区分原装正品和翻新/散新件
4. 小批量可以直接现场交易，大批量建议签合同
5. 带上名片，建立长期合作关系

### 3.2.3 行业展会

| 展会名称 | 时间 | 地点 | 适合找什么 |
|----------|------|------|-----------|
| 深圳国际电子展(ELEXCON) | 每年12月 | 深圳 | 电子元器件、方案商 |
| 慕尼黑上海电子展 | 每年7月 | 上海 | 高端元器件、测试设备 |
| 广交会（中国进出口商品交易会） | 每年4月/10月 | 广州 | 各类制造商 |
| 中国国际高新技术成果交易会 | 每年11月 | 深圳 | 科技产品、投资机构 |

**参展技巧**：
1. 提前在展会官网查看参展商目录，筛选目标
2. 准备好产品简介和需求说明
3. 收集名片，展后及时跟进
4. 很多好的合作关系都是在展会上建立的

### 3.2.4 方案公司（Design House）

**什么是方案公司？**

方案公司是专门为客户提供产品设计方案的公司。你告诉他们你想做什么产品，他们帮你完成从电路设计到固件开发的全部技术工作。

**适合人群**：没有技术能力但有产品创意和资金的创业者。

**如何找靠谱的方案公司**：
1. 华强北周边有大量方案公司
2. 1688搜索"方案开发 + 你的品类"
3. 行业展会
4. 知乎、电子发烧友论坛等社区

**合作注意事项**：
- 要求对方提供过往案例
- 明确交付物（原理图、PCB文件、固件源码、BOM）
- 签订合同，约定源码和知识产权归属
- 分阶段付款，不要一次性付清

### 3.2.5 熟人推荐与行业社群

- **微信群**：硬件创业者社群、电子工程师群
- **论坛**：电子发烧友(elecfans.com)、立创开源硬件平台
- **知乎**：搜索相关话题，关注行业大V
- 熟人推荐的工厂通常**可靠性更高**，是最好的渠道之一

## 3.3 各类供应商选择指南

### 3.3.1 PCBA 加工厂（SMT贴片厂）

PCBA = PCB + Assembly，即把元器件焊接到PCB板上。

**选择要点**：

| 评估项目 | 小批量(< 100片) | 中批量(100-5,000片) | 大批量(> 5,000片) |
|----------|-----------------|-------------------|------------------|
| 推荐选择 | 嘉立创SMT | 中小型贴片厂 | 大型EMS工厂 |
| 价格 | 较高 | 中等 | 最低 |
| 起订量 | 5片起 | 50-100片起 | 500-1,000片起 |
| 品控 | 标准 | 较好 | 最严格 |
| 周期 | 3-5天 | 5-10天 | 7-15天 |

**关注指标**：
- 贴片精度（0402/0201器件能力）
- BGA焊接能力
- AOI/X-Ray检测设备
- 是否提供代购元器件服务

### 3.3.2 模具厂与注塑厂

**选择模具厂的关键**：
1. **看案例**：要求看与你产品类似的模具作品
2. **看设备**：CNC加工中心的品牌和精度（发那科、三菱等）
3. **看报价明细**：好的模具厂会提供详细的模具结构和报价明细
4. **看沟通**：能否理解你的设计意图，是否提出改进建议

**常见问题**：
- 外观面的抛光要求（镜面SPI-A1，半光SPI-B1等）
- 脱模角度（一般1-3°）
- 进胶点位置（影响外观）

### 3.3.3 组装厂

| 类型 | 适用 | 费用 | 说明 |
|------|------|------|------|
| 手工组装 | < 500台 | ¥10-30/台 | 灵活，适合小批量 |
| 半自动产线 | 500-5,000台 | ¥5-15/台 | 需要简单治具 |
| 全自动产线 | > 5,000台 | ¥3-8/台 | 需要投入自动化设备 |

## 3.4 如何评估工厂

### 工厂评估清单

使用以下清单对候选工厂打分（每项1-5分）：

| 评估项目 | 评估内容 | 权重 | 得分 |
|----------|----------|------|------|
| **资质认证** | ISO9001、ISO14001 等 | 15% | |
| **产能规模** | 月产能是否满足需求 | 10% | |
| **设备水平** | 核心设备品牌和新旧程度 | 10% | |
| **品控体系** | 是否有完善的检验流程 | 15% | |
| **过往案例** | 是否做过类似产品 | 15% | |
| **最小起订量(MOQ)** | 是否接受你的订单量 | 10% | |
| **价格水平** | 在合理范围内 | 10% | |
| **沟通响应** | 回复速度和专业程度 | 10% | |
| **付款灵活度** | 付款方式和账期 | 5% | |

> **经验之谈**：不要只看价格。最便宜的工厂往往意味着最多的品质问题。建议选择**中等价位、沟通顺畅、品控严格**的工厂。

### 实地验厂

如果订单金额较大（¥50,000+），强烈建议实地验厂：

1. 观察车间的 **5S管理**（整理、整顿、清扫、清洁、素养）
2. 看员工是否有规范的操作流程
3. 检查来料区、成品区的标识管理
4. 询问不良品的处理流程
5. 观察测试设备和检验记录

## 3.5 合作模式

| 模式 | 全称 | 你提供 | 工厂提供 | 适合 | 成本 |
|------|------|--------|----------|------|------|
| **OEM** | Original Equipment Manufacturer | 完整设计方案 | 制造和组装 | 有设计能力的团队 | 最低 |
| **ODM** | Original Design Manufacturer | 需求和品牌 | 设计+制造 | 无技术能力的创业者 | 中等 |
| **JDM** | Joint Design Manufacturer | 需求+部分设计 | 联合设计+制造 | 有部分技术能力 | 中等 |

### OEM（代工模式）

你完成所有设计（电路、结构、固件），工厂只负责制造。

- **优点**：成本最低，完全掌控设计
- **缺点**：需要自己有技术能力
- **适合**：学完本课程的你

### ODM（设计+代工模式）

工厂有现成的产品方案，你只需要选择方案并贴上自己的品牌。

- **优点**：速度快、省心
- **缺点**：产品差异化小，方案不独占
- **适合**：快速进入市场、不追求技术独特性

### JDM（联合设计模式）

你和工厂共同完成设计。比如你负责固件和App，工厂负责硬件和结构。

- **优点**：取长补短
- **缺点**：沟通成本高，知识产权需要明确约定
- **适合**：有部分技术能力的团队

## 3.6 商务谈判与合同要点

### 询价技巧

1. **准备详细的技术资料**：提供完整的BOM、PCB文件、结构图，才能获得准确报价
2. **同时向3-5家工厂询价**：对比价格和服务
3. **明确报价包含范围**：是否含税、是否含运费、是否含测试
4. **询问阶梯价格**：100/500/1000/5000台各是什么价格
5. **不要一上来就砍价**：先了解清楚，合理的利润空间才能保证品质

### 合同关键条款

1. **交付内容**：明确列出所有交付物及其规格
2. **交付时间**：约定明确的交付日期和延期罚则
3. **品质标准**：约定良率标准和不良品处理方式
4. **付款方式**：常见的付款节点如下

```
常见付款方式：

方式一：30/70（最常见）
  - 下单付30%预付款
  - 交货验收后付70%尾款

方式二：30/30/40
  - 下单付30%
  - 大货生产前付30%
  - 交货验收后付40%

方式三：月结30天（需要有合作基础）
```

5. **保密条款**：约定工厂不得泄露你的设计方案
6. **知识产权归属**：明确设计文件、模具等的所有权

## 3.7 知识产权保护

### NDA（保密协议）

在向任何工厂或合作方透露设计方案前，务必签署 NDA。

NDA 应包含：
- 保密信息的定义范围
- 保密期限（通常3-5年）
- 违约赔偿条款
- 适用法律和管辖法院

### 专利保护

| 专利类型 | 保护对象 | 保护期限 | 费用 | 申请周期 |
|----------|----------|----------|------|----------|
| 发明专利 | 技术方案 | 20年 | ¥5,000-15,000 | 1-3年 |
| 实用新型 | 产品结构/形状 | 10年 | ¥2,000-5,000 | 6-12个月 |
| 外观设计 | 产品外观 | 15年 | ¥1,500-3,000 | 3-6个月 |

> **建议优先申请**：外观设计专利（快、便宜、保护外观）+ 实用新型专利（保护结构）。发明专利周期长，适合核心技术。

### 商标注册

产品上市前务必注册商标。商标注册费约 ¥300-1,000（官费+代理费），周期约6-12个月。

## 3.8 案例：为「智能环境监测器」寻找供应商

### 需要的供应商清单

| 需求 | 推荐渠道 | 预估费用 |
|------|----------|----------|
| 电子元器件 | 立创商城 / 华强北 | BOM成本¥25/台 |
| PCB打样 | 嘉立创 | ¥5-30/5片 |
| PCB量产+SMT | 嘉立创 或 中小贴片厂 | ¥8-15/片 |
| 注塑外壳 | 1688搜索"注塑加工" | 模具¥35,000 + ¥8/件 |
| 组装测试 | PCBA厂 或 独立组装厂 | ¥5-10/台 |
| 包装 | 1688搜索"彩盒定制" | ¥3-5/套 |

### 实际操作步骤

1. 在立创商城完成 BOM 配单，确认所有元器件有货且价格合理
2. 在嘉立创下单 PCB 打样（5片），同时使用其 SMT 服务
3. 在 1688 搜索"塑料注塑 小家电外壳"，联系3-5家模具厂询价
4. 打样验证通过后，选定最终供应商签订合同
5. 安排小批量试产（100台），验证整个供应链

## 3.9 实践练习

### 练习：为你的产品列出供应商清单

**1. 明确你的需求**

| 需求项目 | 具体描述 | 数量 |
|----------|----------|------|
| PCB + SMT | （板子描述） | ___ 片 |
| 外壳 | （材质、工艺） | ___ 件 |
| 元器件 | （BOM清单） | ___ 套 |
| 组装测试 | （工序描述） | ___ 台 |
| 包装 | （包装形式） | ___ 套 |

**2. 寻找候选供应商**

每个需求至少找3家候选供应商，记录以下信息：
- 公司名称
- 联系方式
- 报价
- 最小起订量
- 交货周期
- 初步评价

**3. 评估与筛选**

使用 3.4 节的评估清单为每家供应商打分，选出最优供应商。
