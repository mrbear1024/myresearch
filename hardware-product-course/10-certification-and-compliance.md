# 第10章：认证与合规

> **学习目标**
> - 理解为什么硬件产品需要认证
> - 了解中国市场（CCC/SRRC）和欧美市场（CE/FCC）的认证要求
> - 掌握认证流程和费用估算
> - 了解常见认证失败原因和解决方案
> - 能为你的产品制定认证计划

---

## 10.1 为什么需要认证？

### 法律要求

- **中国**：部分品类产品必须获得 CCC 认证才能在市场销售
- **欧洲**：所有电子产品必须通过 CE 认证才能进入欧盟市场
- **美国**：电子产品必须通过 FCC 认证
- **不做认证的后果**：罚款、产品下架、禁止销售

### 平台要求

| 平台 | 认证要求 |
|------|----------|
| 天猫/京东 | 需要 CCC 认证或质检报告 |
| 亚马逊（美国站） | 需要 FCC 认证 |
| 亚马逊（欧洲站） | 需要 CE 认证 |
| Kickstarter | 建议有 FCC/CE（增加可信度） |
| 淘宝C店 | 要求较低，但建议有质检报告 |

## 10.2 中国市场认证

### 10.2.1 CCC 认证（中国强制性产品认证）

**适用品类**：电子电器产品、音视频设备、信息技术设备等（有明确的产品目录）。

> **注意**：不是所有电子产品都需要CCC认证。很多IoT小设备、传感器设备不在CCC目录内。需要先查询你的产品是否在目录中。

| 项目 | 详情 |
|------|------|
| 全称 | China Compulsory Certification |
| 标志 | CCC标志（印在产品和包装上） |
| 费用 | ¥20,000 - 50,000 |
| 周期 | 2-3个月 |
| 有效期 | 5年（需年审） |
| 检测内容 | 安全、EMC |
| 发证机构 | 中国质量认证中心(CQC)等 |

### 10.2.2 SRRC（无线电型号核准）

**凡是含有无线发射功能的设备，都必须取得 SRRC 认证。**

这意味着如果你的产品使用 WiFi、蓝牙、LoRa、NB-IoT 等无线通信，就需要 SRRC。

| 项目 | 详情 |
|------|------|
| 全称 | State Radio Regulation Committee |
| 费用 | ¥15,000 - 30,000 |
| 周期 | 4-8周 |
| 测试内容 | 发射功率、频率范围、带宽、杂散发射 |
| 样品数 | 通常3-5台 |

> **提示**：如果你使用的是已经获得SRRC认证的模组（如乐鑫的ESP32模组），可以引用模组的认证，简化流程。但最终产品通常仍需要单独认证。

### 10.2.3 其他国内认证

| 认证 | 适用 | 是否强制 | 费用 |
|------|------|----------|------|
| CQC（自愿性认证） | CCC目录外的产品 | 否 | ¥10,000-30,000 |
| 入网许可 | 通信终端设备 | 是（电信设备） | ¥30,000-80,000 |
| 质检报告 | 电商平台上架 | 看平台要求 | ¥3,000-8,000 |

## 10.3 欧美市场认证

### 10.3.1 CE 认证（欧洲）

CE 不是单一认证，而是一系列指令的合规标志：

| 指令 | 全称 | 适用 | 费用 |
|------|------|------|------|
| **LVD** | 低电压指令 | 交流50-1000V / 直流75-1500V的设备 | ¥5,000-15,000 |
| **EMC** | 电磁兼容指令 | 所有电子电气设备 | ¥5,000-15,000 |
| **RED** | 无线电设备指令 | 含无线功能的设备 | ¥10,000-25,000 |
| **RoHS** | 有害物质限制 | 所有电子电气设备 | ¥3,000-8,000 |
| **REACH** | 化学品法规 | 含化学物质的产品 | ¥3,000-10,000 |

> **大多数IoT产品需要**：EMC + RED + RoHS，总费用约 ¥15,000-30,000。

### 10.3.2 FCC 认证（美国）

| 类型 | 全称 | 适用 | 费用 | 周期 |
|------|------|------|------|------|
| **FCC SDoC** | Supplier's Declaration of Conformity | 无意辐射设备（无无线功能） | ¥8,000-15,000 | 2-3周 |
| **FCC ID** | FCC Identifier | 有意辐射设备（WiFi/BLE等） | ¥15,000-30,000 | 4-6周 |

> **含WiFi/蓝牙的产品**需要 FCC ID认证。

### 10.3.3 UL 认证（安全认证）

| 项目 | 详情 |
|------|------|
| 费用 | ¥50,000-200,000+ |
| 周期 | 2-6个月 |
| 性质 | 非强制，但北美市场高度认可 |
| 建议 | 大品牌/高端产品考虑，初创产品可后期补 |

## 10.4 其他认证与标准

### IP 防水防尘等级

| IP等级 | 防尘（第1位） | 防水（第2位） | 常见应用 |
|--------|-------------|-------------|----------|
| IP20 | 防>12mm物体 | 无防水 | 室内设备 |
| IP44 | 防>1mm物体 | 防溅水 | 普通户外 |
| IP54 | 防灰尘 | 防溅水 | 工业设备 |
| IP65 | 完全防尘 | 防低压水柱 | 户外设备 |
| IP67 | 完全防尘 | 短时间浸水(1m/30min) | 手机、手表 |
| IP68 | 完全防尘 | 持续浸水 | 潜水设备 |

### 电池相关认证

| 认证 | 适用 | 费用 | 说明 |
|------|------|------|------|
| **UN38.3** | 含锂电池的运输 | ¥5,000-15,000 | 航空/海运运输必需 |
| **GB31241** | 国内锂电池安全 | ¥8,000-20,000 | 国内销售建议做 |
| **IEC62133** | 国际锂电池安全 | ¥15,000-30,000 | 出口必需 |

> **重要**：含锂电池的产品如果要出口或空运，UN38.3 是必需的。

### 蓝牙 BQB 认证

使用蓝牙技术的产品需要取得蓝牙技术联盟(SIG)的认证。

| 方式 | 费用 | 说明 |
|------|------|------|
| 引用已认证模组 | $8,000（SIG会费） | 最省钱的方式 |
| 完全新认证 | $8,000 + 测试费 ¥30,000+ | 自研蓝牙方案 |

> **建议**：使用已通过BQB认证的模组（如ESP32），只需缴纳SIG年费并做产品列名即可。

## 10.5 认证流程详解

### 通用流程

```
确定认证项目 → 选择实验室 → 提交申请 → 准备样品和资料 → 预测试(可选)
→ 正式测试 → 出具报告 → 审核发证 → 获取证书
                ↓(不通过)
            整改 → 复测
```

### 需要准备的资料

| 资料 | 说明 |
|------|------|
| 产品说明书 | 中英文 |
| 电路原理图 | 完整原理图 |
| PCB Layout | 含层次图 |
| BOM 清单 | 关键器件的规格书 |
| 产品照片 | 外观、内部、铭牌 |
| 关键元器件认证证书 | 电源适配器UL证书等 |
| 方框图 | 产品功能方框图 |
| 使用说明 | 操作手册 |

### 样品数量

| 认证 | 样品数 | 是否返还 |
|------|--------|----------|
| CCC | 2-4台 | 通常不返还 |
| SRRC | 3-5台 | 通常不返还 |
| CE(EMC) | 2台 | 可返还 |
| FCC ID | 2-3台 | 可返还 |

## 10.6 认证实验室选择

### 国际知名机构

| 机构 | 全称 | 特点 | 适合 |
|------|------|------|------|
| **SGS** | 通标标准技术服务 | 全球最大、网点最多 | 出口产品 |
| **TUV** | 德国技术监督协会 | 欧洲认可度最高 | 欧洲市场 |
| **BV** | 必维国际检验集团 | 服务好、价格中等 | 综合类 |
| **Intertek** | 天祥集团 | ETL认证（UL替代） | 北美市场 |

### 国内机构

| 机构 | 特点 | 适合 |
|------|------|------|
| **CQC** | 中国质量认证中心 | CCC认证首选 |
| **赛宝(CEPREI)** | 电子信息行业 | 电子产品 |
| **泰尔实验室** | 通信行业 | 入网许可 |
| **各地检测院** | 价格便宜 | 质检报告 |

### 选择建议

| 场景 | 推荐选择 | 理由 |
|------|----------|------|
| 只做国内市场 | 国内检测院 + CQC | 价格最优 |
| 国内+欧洲 | SGS 或 TUV | 一次测试出多份报告 |
| 国内+美国 | SGS 或 Intertek | 同上 |
| 预算有限 | 淘宝搜索"FCC认证" | 很多代理价格更低 |

## 10.7 常见认证失败原因与解决方案

| 序号 | 失败原因 | 解决方案 |
|------|----------|----------|
| 1 | **辐射发射超标** | 加屏蔽罩、优化PCB布局、加磁珠/滤波器 |
| 2 | **传导发射超标** | 加共模电感、加Y电容、优化电源滤波 |
| 3 | **ESD防护不足** | 加TVS管、优化接地设计 |
| 4 | **浪涌/雷击不通过** | 加压敏电阻、气体放电管 |
| 5 | **谐波电流超标** | 使用PFC电源方案 |
| 6 | **接地连续性不合格** | 优化接地设计和连接 |
| 7 | **铭牌/标识不规范** | 按标准要求修改标识 |
| 8 | **说明书缺少安全警告** | 添加必要的安全提示语 |

### EMC 问题预防

EMC（电磁兼容）问题是认证中最常见的失败原因。预防措施：

1. **PCB设计阶段**：
   - 完整的地平面
   - 信号线不要跨越地平面分割
   - 高速信号做阻抗控制
   - 电源入口加滤波电路

2. **结构设计阶段**：
   - 金属外壳天然提供屏蔽
   - 塑料外壳考虑内部加屏蔽罩
   - 接缝处注意电磁泄漏

3. **固件阶段**：
   - WiFi发射功率不要超过法规限制
   - 控制时钟频率的谐波

## 10.8 产品标识与包装要求

### 产品铭牌必备信息

| 信息 | 中国 | CE | FCC |
|------|------|-----|-----|
| 产品名称 | ✓ | ✓ | ✓ |
| 型号 | ✓ | ✓ | ✓ |
| 制造商名称 | ✓ | ✓ | ✓ |
| 制造商地址 | ✓ | — | — |
| 输入电压/电流 | ✓ | ✓ | ✓ |
| 认证标志 | CCC标志 | CE标志 | FCC ID |
| 生产日期/批次 | ✓ | — | — |
| 警告标识 | 视产品 | 视产品 | 视产品 |

### 包装上的认证标志

```
常见认证标志位置：包装背面或底部

[CCC] [CE] [FCC] [RoHS] [回收标志] [WEEE]
```

### 说明书必备内容

- 产品功能介绍
- 使用方法
- 安全注意事项（必须有！）
- 保修条款
- 制造商联系方式
- 认证信息
- 法律声明

## 10.9 案例：「智能环境监测器」认证规划

### 目标市场：国内电商

| 认证项目 | 必要性 | 预估费用 | 周期 |
|----------|--------|----------|------|
| SRRC | 必需（含WiFi+BLE） | ¥20,000 | 6周 |
| 质检报告 | 必需（电商上架） | ¥5,000 | 2周 |
| CCC | 查询后确认是否需要 | ¥30,000 | 8周 |
| RoHS | 建议做 | ¥3,000 | 1周 |
| **总计** | | **¥28,000-58,000** | |

### 如果同时卖海外（亚马逊美国站）

额外需要：
| 认证项目 | 费用 | 周期 |
|----------|------|------|
| FCC ID | ¥20,000 | 4周 |
| UN38.3（含锂电池） | ¥8,000 | 3周 |
| **额外费用** | **¥28,000** | |

### 认证时间规划

建议在 **DVT 阶段**就开始认证准备：
1. DVT 初期：选定认证实验室，了解要求
2. DVT 中期：做 EMC 预测试，发现问题及时修改
3. DVT 后期：正式送样测试
4. PVT 阶段：获取证书，准备量产
