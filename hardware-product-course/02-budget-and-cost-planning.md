## 2.1 为什么硬件产品需要认真做预算？

硬件产品与软件产品最大的区别之一就是**前期投入大、试错成本高**。软件产品写错了可以重新部署，而硬件产品一旦开模、量产，修改的代价是巨大的。

常见的预算失控场景：

- 开模后发现设计缺陷，需要重新开模（浪费 ¥20,000-200,000）
- 认证不通过需要改板重测（浪费 ¥10,000-50,000 + 2个月时间）
- 首批量产良率太低，大量返工或报废
- 低估了包装、物流、售后等隐性成本

**做好预算是硬件创业成功的第一步。**

## 2.3 BOM 成本估算

### 2.3.1 什么是 BOM？

BOM（Bill of Materials，物料清单）是硬件产品的"食材清单"，列出了制造一台产品所需的所有元器件和材料。

BOM 是硬件产品最核心的文档之一，贯穿设计、采购、生产全流程。

### 2.3.2 BOM 表格式

一份标准的 BOM 表应包含以下字段：

| 序号 | 位号 | 描述 | 封装 | 数量 | 品牌/型号 | 单价(1K) | 小计 | 替代料 | 备注 |
|------|------|------|------|------|-----------|----------|------|--------|------|
| 1 | U1 | MCU | QFN-32 | 1 | ESP32-C3 | ¥8.5 | ¥8.5 | ESP32-C3-MINI | 主控 |
| 2 | U2 | 温湿度传感器 | DFN-8 | 1 | SHT30-DIS | ¥6.0 | ¥6.0 | DHT22 | |
| 3 | U3 | LDO稳压器 | SOT-23-5 | 1 | AMS1117-3.3 | ¥0.3 | ¥0.3 | ME6211 | 3.3V输出 |
| 4 | R1-R10 | 电阻 | 0402 | 10 | - | ¥0.005 | ¥0.05 | | 混合阻值 |
| 5 | C1-C8 | 电容 | 0402 | 8 | - | ¥0.01 | ¥0.08 | | 混合容值 |
| ... | ... | ... | ... | ... | ... | ... | ... | ... | ... |
| | | | | | | **BOM总计** | **¥25.3** | | |

### 2.3.3 BOM 成本优化技巧

1. **选择国产替代芯片**：很多国产芯片性能接近进口芯片，价格便宜30-70%
2. **减少BOM种类**：统一电阻电容规格，减少物料管理复杂度
3. **批量采购谈价**：1K vs 10K 价格可能差30-50%
4. **选择通用封装**：避免特殊封装，降低PCB设计和贴片成本
5. **合理选择精度**：不需要1%精度的电阻就用5%的，价格差5-10倍
6. **关注MOQ（最小起订量）**：有些芯片MOQ很高，小批量会造成库存积压

### 2.3.4 从BOM到产品总成本

```
产品总成本 = BOM成本 + PCB成本 + SMT加工费 + 外壳成本 + 组装费 + 测试费 + 包装费
           + (模具费 ÷ 预计产量)
           + (认证费 ÷ 预计产量)
           + 管理费（约10%）
           + 不良品损耗（约3-5%）
```

**示例计算（智能环境监测器，1000台）**：

| 成本项 | 单台成本 |
|--------|----------|
| BOM（电子元器件） | ¥25.0 |
| PCB板 | ¥3.0 |
| SMT 加工 | ¥5.0 |
| 外壳（注塑件） | ¥8.0 |
| 组装 | ¥5.0 |
| 测试 | ¥2.0 |
| 包装（彩盒+说明书） | ¥5.0 |
| 模具分摊（¥30,000÷1000） | ¥30.0 |
| 认证分摊（¥40,000÷1000） | ¥40.0 |
| 管理费（10%） | ¥12.3 |
| 不良品损耗（5%） | ¥6.2 |
| **单台总成本** | **¥141.5** |

> 建议零售价 = 总成本 × 3~5 = **¥425 - ¥708**

## 2.5 资金来源与融资渠道

### 自有资金

最稳妥的方式。建议至少准备计划预算的 **1.5 倍**作为资金储备（应对超支）。

### 众筹

| 平台 | 特点 | 费用 | 适合产品 |
|------|------|------|----------|
| Kickstarter | 全球最大众筹平台，适合创新产品 | 平台费5%+支付费3-5% | 新奇特、设计感强的产品 |
| Indiegogo | 门槛略低，支持灵活目标 | 平台费5% | 科技产品、生活用品 |
| 京东众筹 | 国内影响力大，转化率高 | 平台费3-5% | 科技、智能硬件 |

> **众筹建议**：众筹不只是融资手段，更是**市场验证**。如果众筹目标都达不到，说明产品市场需求可能不足。

### 天使投资

适合有明确商业模式和团队的项目。硬件领域常见的早期投资机构包括：HAX（硬件加速器）、创新工场、真格基金等。

### 政府补贴

- 国家高新技术企业认定
- 各地科技创新资金
- 专利资助
- 中小企业发展基金

## 2.6 成本控制技巧

### 10个实用技巧

1. **先用开发板验证，再做定制PCB** — 不确定的方案不要急着画板
2. **选择集成度高的芯片** — 比如ESP32自带WiFi+蓝牙，省去外挂模块
3. **国产替代** — 电源芯片、运放、MOS管等有大量优质国产替代
4. **合并SMT和组装到同一家工厂** — 减少中间物流和管理成本
5. **PCB拼板** — 小板子拼在一起打样/量产，降低单板成本
6. **使用公版方案** — 很多方案公司提供成熟的参考设计
7. **3D打印先验证再开模** — 避免模具修改带来的巨大浪费
8. **选择合适的PCB层数** — 能用双面板解决的不要用四层板
9. **物料统一规格** — 电阻电容尽量用相同封装和少数几种阻值/容值
10. **阶梯式量产** — 先做500台测试市场，再追加订单

### 5个常见陷阱

| 陷阱 | 后果 | 如何避免 |
|------|------|----------|
| 没做充分验证就开模 | 模具报废，损失数万元 | 3D打印→CNC手板→铝模小批量→钢模量产 |
| 低估认证费用和时间 | 产品无法按时上市 | 项目初期就规划认证，预留充足预算 |
| BOM选用停产/缺货芯片 | 量产时买不到料 | 查询芯片生命周期，选择备选方案 |
| 忽略包装和物流成本 | 总成本超出预期10-20% | 在BOM估算时就加入包装物流成本 |
| 只看单价不看总成本 | 贪便宜选了差元件导致良率低 | 综合考虑质量和售后成本 |
